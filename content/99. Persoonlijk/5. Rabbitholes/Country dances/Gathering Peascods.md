# Gathering Peascods
![[15 Gathering Peascods.mp3]]
![[99. Persoonlijk/1. Larp/2. Ekyo/Archief/0. PDFs & docs/Bladmuziek/Erwtenoogst.pdf|Erwtenoogst]]
This is not danced in quartets. Instead, make a full circle of alternating leaders and followers. Leaders stand to the left of 'their' follower. Start the circle with joined hands. 

| Count | Description                                                                 |
| ----- | --------------------------------------------------------------------------- |
| 2x4   | All go to the left                                                          |
| 1x4   | Turn single                                                                 |
| 2x4   | All go to the right                                                         |
| 1x4   | Turn single                                                                 |
| 3x4   | Leaders go forward, join hands, go round (left) full circle and return      |
| 3x4   | Followers go forward, join hands, go round (right) full circle and return   |
| 1x4   | Leaders go forward, clap hands                                              |
| 1x4   | Followers go forward, clap hands, while leaders return                      |
| 1x4   | Leaders go forward, clap hands, while followers return                      |
| 1x4   | Leaders turn single backwards to return                                     |
| 4x4   | Followers forward and clap, etc. (full cycle)                               |
