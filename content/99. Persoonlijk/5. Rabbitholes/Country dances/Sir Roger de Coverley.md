# Sir Roger de Coverley
This dance is mostly performed by the primary pair and the *ultimate pair* in the longdance. Everyone in between can gossip. Ideally, lines should not be too long as to be impossible. We've done it with 6 pairs (so 1&6 while 2-5 can chill). 

| Count | Description                                                                                    |
| ----- | ---------------------------------------------------------------------------------------------- |
| 1x3   | PL+UF three steps/skips towards each other                                                     |
| 1x3   | PL+UF three steps/skips backwards to start                                                     |
| 1x3   | PF+UL three steps/skips towards each other                                                     |
| 1x3   | PF+UL three steps/skips backwards to start                                                     |
| 1x6   | PL+UF meet in the middle, right-hand turn, return                                              |
| 1x6   | PF+UL meet in the middle, right-hand turn, return                                              |
| 1x6   | PL+UF meet in the middle, left-hand turn, return                                               |
| 1x6   | PF+UL meet in the middle, left-hand turn, return                                               |
| 1x6   | Primary pair cast down, rest follows in lines                                                  |
| 1x6   | Primary pair makes an arch, rest goes through<br>(effectively a progression as P stays behind) |
