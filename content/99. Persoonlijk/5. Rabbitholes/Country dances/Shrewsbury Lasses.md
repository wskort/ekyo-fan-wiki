# Shrewsbury Lasses
Danced in three pairs, so Primary, Secondary and Tertiary pairs. This also means that there are two rounds to wait out at the ends of the line. 

| Count | Description                                                                                                                                   |
| ----- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| 1x4   | Primary leader + secondary follower ballonné 2x forward                                                                                       |
| 1x4   | Honours (PL bows, SF curties)                                                                                                                 |
| 1x8   | PL+SF 2-hand full turn                                                                                                                        |
| 1x4   | Primary follower + secondary leader ballonné 2x forward                                                                                       |
| 1x4   | Honours (PF curties, SL bows)                                                                                                                 |
| 1x8   | PF+SL 2-hand full turn                                                                                                                        |
| 1x4   | Primary pair cast out downstairs while secondary pair progression upstairs                                                                    |
| 1x8   | Primary pair and Tertiary pair join hands and turn full circle clockwise                                                                      |
| 1x8   | Primary leader casts around Secondary Pair while Primary follower casts around Tertiary pair to end in between S and T in 'improper' position |
| 1x4   | Primary pair 2-hand turn (switch)                                                                                                             |
