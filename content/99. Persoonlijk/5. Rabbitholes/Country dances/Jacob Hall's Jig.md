# Jacob Hall's Jig
| Count | Description                                                                                                         |
| ----- | ------------------------------------------------------------------------------------------------------------------- |
| 1x8   | Primary leader and Secondary follower right-hand full turn                                                          |
| 1x8   | Primary leader and *both followers* join hands full turn clockwise                                                  |
| 1x8   | Secondary leader and Primary follower left-hand full turn                                                           |
| 1x8   | Secondary leader and both followers join hands full turn *counter-clockwise*                                        |
| 1x4   | Primary pair promenade downstairs                                                                                   |
| 1x4   | Primary pair turns around and promenade upstairs (forwards) to sides of secondary pair                              |
| 1x4   | *As a line* Primary and secondary pair promenade upstairs                                                           |
| 1x4   | *Backwards* Primary and secondary pair promenade downstairs (and secondary pair folds in upstairs to form a circle) |
| 1x8   | As a circle, both pairs join hands and full turn clockwise                                                          |
| 1x8   | Primary pair cast out downstairs while secondary pair progress upstairs                                             |
