# Naamkaartjes

-   Voornaam
-   [[Achternaam]] (links to faction [[Mercantielen]], [[Patriotten]] or [[Orangisten]])
-   evt. factiekleur
-   [[Rijkdom]] niveau (1-4)
-   [[Aanzien]] niveau (1-4)
-   Burgerlijke staat (unmarried, married, widowed) (zie ook [[Man-vrouw verhoudingen]])
-   Ruimte voor 3 [[Spelkalibratie]] bedeltjes
 
Mogelijke formaten:

|                         | L   | B    |
| ----------------------- | --- | ---- |
| Standaard visitekaartje | 8,5 | 5,5  |
| Half visitekaartje      | 5,5 | 4,25 |
| Zichtbaar deel          | 7,5 | 4,5  |
| Volledig blok           | 10  | 7,5  |
