# Adapted pelerine historybound
Yarn: Gomitolo Aloha (Lana Grossa)
50% cotton, 50% viscose
100g / 250m
3,0 crochet hook

## Neck (work in BLO)
| Row  | Instructions                                           | num |
| ---- | ------------------------------------------------------ | --- |
| 0    | Chain 21                                               | 21  |
| 1    | Skip first chain, 5sc, 5hdc, 5dc, 5tc                  | 20  |
| 2    | Ch3 (doesn't count), 5tc, 5dc, 5hdc, 5sc               | 20  |
| 3    | Ch1 (doesn't count), 5sc, 5hdc, 5dc, 5tc               | 20  |
| 4-49 | Repeat rows 2 and 3                                    | 20  |
| 50   | Ch3 (doesn't count), 5tc, 5dc, 5hdc, ch4 (skip 4), 1sc | 20  |
| 51   | Repeat row 3                                           | 20  |

## Collar
| Row | Instructions                                                                                                                                                                                                                                    | num |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- |
| 1   | Align points, and sc around outer edge starting with across, then sl st in first sc                                                                                                                                                             | 150 |
| 2   | Ch(counts as DC + ch 1), '{DC, Ch 1} in next st, repeat from ' around entire piece. End with ch 1, sl st to 3rd ch of beginning ch4                                                                                                             | 150 |
| 3   | Sl st into ch 1 sp, Ch 1, {3DCTOG, Ch 2, 3DCTOG} in same sp (center back), '{Ch 1, 3DCTOG in next ch sp} 19 times, ch 1, {3DCTOG, Ch 2, 3DCTOG} in next ch sp, repeat from ' around ending with ch 1 and sl st to first 3DCTOG.                 | 154 |
| 4   | Sl st into ch 2 sp, {2 SC, ch 2, 2 SC} in ch 2 sp, 'SC in each 3DCTOG AND in each ch 1 sp until next corner, {2 SC, ch 2, 2 SC} in next ch 2 sp, repeat from ' around, ending with sc in last ch sp, sl st to first st.                         |     |
| 5   | Sl st into corner ch 2 sp, Ch 3, sl st back into the ch 2 sp, 'Ch 3, sk 2 sts, sl st in next st, repeat from ' until next corner sl st into corner, ch 3, sl st back into corner ch 2 sp, repeat from ' around, sl st to first ch of beg. ch 3. |     |
