# Grauwe Dag
![[Grauwe dag.mp3]]

```
Ik graaf hier mijn gat
Spaar mijn Knopen voor een grauwe dag
Ik graaf hier mijn gat
Sprokkel Knopen voor die grauwe dag
Ik ben veilig

Ik bouw hier mijn muur 
Om te schuilen voor de lange duur 
Ik bouw hier mijn muur 
Ik blijf schuilen voor de lange duur 
Ik ben veilig, ik blijf veilig

Ga zonder harnas aan
Ik blijf liever staan
Deze oorlog gaat mij toch niets aan
Ik blijf hier wel staan

Ik weet nergens van
Jouw geheimen heb ik nooit gehoord
En ik spreek nergens van
Ik blijf zwijgen tot het laatste woord
Ik ben veilig, ik blijf veilig

Ga zonder harnas aan
Ik blijf liever staan
Deze oorlog kan ik toch niet aan
Ik blijf hier wel staan
Niet alsof ik zou kunnen helpen
Laat mij hier maar staan

Zwarte wolken, zware longen 
Ik blijf veilig op die grauwe dag 
Zon verduisterd, tranende ogen 
Ik blijf veilig op die grauwe dag 
Open gaten in de muren 
Blijf ik veilig op die grauwe dag?
```
