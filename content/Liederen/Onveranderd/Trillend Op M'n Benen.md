# Trillend Op M'n Benen

```
Ik val naar beneden, donker gat daar lig ik in
Weet niet eens waar het vandaan komt maar ik zit er middenin
Kan ik nog omhoog uit een dal dat ik niet ken?
Ik denk het wel als ik weet wie ik in werkelijkheid ben

Waar hou ik aan vast als er niks is om op te bouwen?
Bij wie kan ik gaan als het niet lukt van mij te houden?
Er komt een stukje terug dat ooit een tijdje was verdwenen
Nu ben ik weer alleen, trillend op m'n benen

Dat kind dat altijd eerder op de toekomst had vertrouwd
Voelt nu even heel ver weg in de val die mij vasthoudt
Kan ik nog omhoog uit een dal dat ik niet ken?
Ik denk het wel als ik weet wie ik in werkelijkheid ben

Waar hou ik aan vast als er niks is om op te bouwen?
Bij wie kan ik gaan als het niet lukt van mij te houden?
Er komt een stukje terug dat ooit een tijdje was verdwenen
Nu ben ik weer alleen, trillend op m'n benen

Morgen zal ik vast wel weer rechtop staan
Ook al valt de bodem weg, ik kan het aan
Ik ben alleen vergeten hoe ik door kan gaan

Waar hou ik aan vast als er niks is om op te bouwen?
Bij wie kan ik gaan als het niet lukt van mij te houden?
Er komt een stukje terug dat ooit een tijdje was verdwenen
Nu ben ik weer alleen, trillend op m'n benen
```
