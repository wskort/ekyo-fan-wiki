# Linux notes

`windows knop` = start

`sudo` = run as root (if you're not root by default)

root directory is the home of the user 'root'. All other users have their home in '/home'

* `cd ~/` means go to this user's home.
* `cat .bash_history` shows terminal history.
* `man [command]` or `help [command]` brings up manual about how to use this command.
* `[SELECT]` the selection is copied to your clipboard; no keys needed.
* `[SHIFT+INS]` paste from clipboard
