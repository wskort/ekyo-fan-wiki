# LaTeX
Inline equation (`$equation$`): $equation$

Display equation (`$$equation$$`): $$equation$$
Colours: `\color{blue}`. 
For example: `$\color{green}\surd$`: $\color{green}\surd$ 
For example: `$\color{red}X$`: $\color{red}X$
