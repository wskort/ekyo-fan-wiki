# Infrastructure Model Exchange (IMX)
One association of the .imx extension belongs to the Autodesk IMX file format. Standing for Infrastructure Model Exchange, IMX is an [[XML]] format specifically designed to facilitate quick and efficient transfer of AutoCAD Civil 3D infrastructure models (roads, etc.) into Autodesk InfraWorks (formerly, Autodesk Infrastructure Modeler, AIM), and vice versa. The .imx file is a 3D model with its metadata exported from Autodesk InfraWorks or AutoCAD Civil 3D. IMX is natively supported by both applications.
