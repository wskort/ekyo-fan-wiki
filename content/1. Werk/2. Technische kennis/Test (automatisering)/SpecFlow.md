## Rapport
Elke run (in [[Azure DevOps]]) draait een [[TRX]] file uit met de testrapportage. Hiervoor is bijvoorbeeld de tool [[ExtendReport]] beschikbaar om het om te zetten naar een mooi geformatteerde rapportage. Dit kan dan bijvoorbeeld aan de Release Notes worden toegevoegd.
