# Open Database Connectivity (ODBC)
In computing, [[ODBC|ODBC (Open Database Connectivity)]] is a standard [[API|API (Application Programming Interface)]] for accessing [[DBMS|DBMS (Database Management Systems)]]s. The designers of [[ODBC]] aimed to make it independent of database systems and operating systems. An application written using [[ODBC]] can be ported to other platforms, both on the client and server side, with few changes to the data access code.
