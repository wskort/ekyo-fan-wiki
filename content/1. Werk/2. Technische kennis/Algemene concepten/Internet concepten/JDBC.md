# Java Database Connectivity (JDBC)
[[JDBC|JDBC (Java Database Connectivity)]] is an [[API|API (Application Programming Interface)]] for the programming language [[Java]], which defines how a client may access a database. It is a Java-based data access technology used for Java database connectivity. It is part of the Java Standard Edition platform, from Oracle Corporation. It provides methods to query and update data in a database, and is oriented toward relational databases. A [[JDBC]]-to-[[ODBC]] bridge enables connections to any [[ODBC]]-accessible data source in the [[JVM|JVM (Java Virtual Machine)]] host environment.
