FTPS (also known FTP-SSL, and FTP Secure) is an extension to the commonly used [[FTP|FTP (File Transfer Protocol)]] that adds support for the [[TLS|TLS (Transport Layer Security)]] and, formerly, the [[SSL|SSL (Secure Sockets Layer)]] (which is now prohibited by [RFC7568](https://tools.ietf.org/html/rfc7568)) cryptographic protocols.

[[FTPS]] should not be confused with the [[SFTP|SFTP (SSH File Transfer Protocol)]], a secure file transfer subsystem for the [[SSH|SSH (Secure Shell)]] protocol with which it is not compatible. It is also different from [[FTP]] over [[SSH]], which is the practice of tunneling [[FTP]] through an [[SSH]] connection.
