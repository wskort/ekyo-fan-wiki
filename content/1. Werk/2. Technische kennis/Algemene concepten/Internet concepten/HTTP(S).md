# Hypertext Transfer Protocol (Secure) (HTTP(S))
[[HTTP(S)|HTTPS (Hypertext Transfer Protocol Secure)]] is an extension of the [[HTTP(S)|HTTP (Hypertext Transfer Protocol)]]. It is used for secure communication over a computer network, and is widely used on the Internet. In [[HTTP(S)|HTTPS]], the communication protocol is encrypted using [[TLS|TLS (Transport Layer Security)]] or, formerly, [[SSL|SSL (Secure Sockets Layer)]]
