# ECT Swaggers
Via de [[ECT VDI]] zijn de urls voor de [[Swagger]] endpoints bereikbaar. 

| Env  | URL                                                              | Machine |
| ---- | ---------------------------------------------------------------- | ------- |
| Test | `http://msacen074.centralarea.acc/{api-naam}/swagger/index.html` | 074 Acc |
| Acc  | `http://msacen048.centralarea.acc/{api-naam}/swagger/index.html` | 048 Acc |
| Prod | `http://mspcen048.centralarea.prd/{api-naam}/swagger/index.html` | 048 Prd |

## Overzicht API's
Om te zien welke api's er beschikbaar zijn en onder welke namen, remote desktop je naar de relevante machine en start je daar via het startmenu [[IIS|Internet Information Services (IIS) Manager]]. Klap de machinenaam uit, dan sites, dan web API, en daar vind je een overzicht van de API's en hun aanroepnamen.
